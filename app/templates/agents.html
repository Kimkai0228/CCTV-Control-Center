Run the same image with agent mode enabled

On the remote campus host, create a compose service from the same image with these environment variables. The agent only needs outbound HTTPS to this host and local access to its NVRs.

RUN_AGENT=true
AGENT_MAIN_URL=https://cctv.footprints.work
AGENT_TOKEN=
AGENT_NAME=TTP campus agent
AGENT_CAMPUS=ttp
AGENT_ZONES=ecp,secondary
AGENT_WORKERS=2
RUN_BOT=false
RUN_SCHEDULER=false
AGENT_KEEP_FILES_DAYS=7

Mount ./agent-data:/app/data and ./lib:/app/lib (Hikvision SDK). For direct downloads, point nginx at port 5555 and expose only /agent-files/, then set the public HTTPS URL above. A ready-made docker-compose.agent.yml and .env.agent.example are included in the project.

The agent token is shown only once when an agent is created or rotated. Rotate it here if a container is lost.
